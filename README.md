# 📝 Registration Form Project

This project features a simple and visually appealing **registration form** built using **HTML5 and CSS3**. It provides a structured layout for collecting user information such as name, email, password, account type, profile picture, age, bio, and terms of service agreement.

## 💡 Features

- Responsive form layout with modern styling
- Client-side validation using HTML attributes
- Radio buttons for account type selection
- Dropdown for referral source
- File upload input for profile picture
- Accessible labels and semantic HTML elements
- Clean and organized CSS styling

## 🚀 Getting Started

To get started with this project:

1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/registration-form-project.git](https://github.com/Joaquimdacosta1999/Registration-Form-Project)
   ```
2. Open the project folder:
   ```bash
   cd registration-form-project
   ```
3. Open `index.html` in your browser to view the form.
